# ⚽ 2026 世界杯竞猜模拟系统

一套完整的世界杯竞猜模拟系统，包含**用户端**、**庄家管理后台**与**实时比分/赔率同步**能力。

> 仅用于学习与技术演示，不涉及任何真实资金交易。

## ✨ 功能特性

### 用户端
- 注册 / 登录（邮箱验证码）、账户余额
- 比赛列表、赛程筛选、实时比分
- 三种玩法：**胜平负**、**让球胜平负**、**大小球**
- 拖拽式投注、赔率展示、中奖记录
- 排行榜 + 弹幕式滚动恭喜（前三名专属金/银/铜特效）

### 庄家管理后台
- 仪表盘总览：平台余额、投注笔数、盈亏统计
- 比赛管理、盘口赔率、用户管理、充值管理
- 投注监控、比赛结算、赔率同步、开奖结果
- **玩法开关**：一键启用/停用某类玩法的投注
- **资金明细**：按时间/类型/用户筛选、分页、导出 CSV
- 数据清零、资金流水统计摘要（收入/支出/净余额）

### 后台能力
- 实时比分同步（每 30 分钟）
- 赔率自动同步调度（每小时）
- 邮件服务（注册验证码）

## 🧱 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Node.js + Express |
| 存储 | 本地 JSON 文件数据库（`worldcup_data.json`） |
| 鉴权 | JWT + bcryptjs |
| 邮件 | Nodemailer（163 SMTP） |
| 前端 | 原生 HTML / CSS / JavaScript |

## 🚀 快速开始

### 1. 安装依赖
```bash
cd backend
npm install
```

### 2. 配置邮件授权码（可选）
复制 `auth-code.txt.example` 为 `auth-code.txt`，填入你的 163 邮箱 SMTP 授权码。
> 不配置也能运行，只是注册验证码邮件无法发送。

### 3. 启动服务
```bash
npm start
```

启动后：

| 入口 | 地址 |
|------|------|
| 用户端 | http://localhost:6789 |
| 管理端 | http://localhost:6789/admin |
| 局域网访问 | http://<本机IP>:6789 |

### 4. 默认庄家账号
```
账号：admin
密码：admin888
二次验证码：888888
```
